Import System configuration

Following elements can be imported

  • Controller (9200, 9230, 9240, 9290)
  • Reader (9104, 9110, 9112, 9115, 9125)
  • Access point (including passageway components)
  • Turnstile (including passageway components)
  • Binary inputs
  • Binary outputs

On re-import only new elements will be imported. Already existing elements will be ignored because Exos 9300 is the master. When a existing element should be imported it has to be deleted first.
